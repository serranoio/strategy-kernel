# Interactive Model Grill

Use this subworkflow when the user needs to understand or pressure-test a
proposed product/system model.

Grill the user through concrete scenarios until they can predict how the model
behaves. Walk down each branch of the decision tree, resolving dependencies
one-by-one.

For each question, provide 2-4 options, mark your recommended answer, and say
why the question matters.

If a question can be answered by exploring the codebase, explore the codebase
instead.

If the user picks a different answer, update the model and continue down that
branch.
