# Strategy Kernel

An agent skill for diagnosing a problem, setting a guiding policy, selecting a solution when alternatives matter, and turning the selected approach into coherent actions.

## Workflow

1. **Diagnosis** — define the problem from evidence. Keep the visible diagnosis problem-oriented.
2. **Guiding Policy** — set direction and decision criteria when they help.
3. **Solution Selection** — compare materially different approaches and pressure-test the choice when alternatives remain.
4. **Coherent Actions** — plan actions after selecting or recommending an approach.

The skill consolidates repeated points, applies the Jaded Architect tone, and uses a focused adversarial review to challenge decision-changing assumptions without turning every response into an exhaustive debate.

## Installation

Clone this repository and copy the entire `strategy-kernel` directory into your agent's skills directory. Keep `SKILL.md` and `references/` together.

## Usage

Ask your agent to use the Strategy Kernel skill to diagnose a problem, choose among solution approaches, or form a coherent action plan.

> Use strategy-kernel to help me decide what to build next and form a coherent action plan.

See [SKILL.md](strategy-kernel/SKILL.md) for the workflow and [references/](strategy-kernel/references/) for supporting guidance.
